II.
MECHANISM

The operation, performed ~10¹⁵ times.

The parameters themselves do nothing. What moves is the multiplication — input vectors meeting weight matrices, billions of small arithmetics per token. Watch one happen.

y = Wx + b · multiply-accumulate

To predict the next word, the model takes a vector x = [0.21, -0.04, 0.78, …] — your sentence, encoded — and multiplies it against a weight matrix W. The result is rotated, stretched, bent into a new shape. Then the next layer does it again.

The weights are frozen. The input flows. Meaning is the shape that survives 96 such transformations.

Each cell that brightens left of the diagonal is one multiplication. A modern model performs roughly a quadrillion of these to read a single page. The parameters are the lookup table; attention is the choreography.
